# Рабочие профили, клоны и второе пространство

**Устанавливайте и настраивайте VPN Hide только в основном профиле.** Java-хуки
работают в общем системном процессе `system_server`; копия в каждом профиле не
нужна. Во вторичных профилях интерфейс приложения заблокирован. При предупреждении
удалите лишние копии.

## Один пакет — один выбор

Список в основном профиле собирает пакеты и их UID из разных профилей. Пакет,
установленный в нескольких профилях, имеет один выбор с указанием профилей в списке.
Роли и настройки хуков применяются ко всем обнаруженным копиям.
**Назначить разные роли личной и рабочей копиям одного пакета нельзя.** Клон с
другим именем пакета можно настроить отдельно.

Лимит Native считается по отдельным UID, а не строкам списка: пакет в двух профилях
обычно занимает два места. Для самого VPN Hide резервируется только UID основного
профиля. См. [Ограничения](capabilities-limits.md).

Если приложения профиля не видны или сканирование неполное, проверьте доступность
профиля и повторите загрузку списка. Отсутствие строки не означает, что сохранённая
конфигурация удалена. Профили и маршрутизация VPN — разные вещи: при диагностике
учитывайте, в каком профиле находится цель и через какой VPN идёт её трафик.
