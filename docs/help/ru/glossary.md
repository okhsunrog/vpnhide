# Словарь терминов

Короткие определения терминов из этого руководства.

- **Бэкенд** — компонент, который выполняет скрытие. У VPN Hide есть **Java**-
  бэкенд (LSPosed) и **native**-бэкенд (kmod, KPM, Zygisk или встроенный). См.
  [Какой Native-бэкенд выбрать](choosing-native.md).
- **Native** — скрытие ниже Java-фреймворка: на уровне ядра или libc, покрывает
  прямые системные вызовы, список интерфейсов, netlink и `/proc/net`.
- **Java-слой / LSPosed** — фреймворк, которым хукается `system_server`, чтобы VPN
  вырезался из сетевых Java-API Android ещё до того, как его увидит приложение.
- **Хук (hook)** — одна точка перехвата. Бэкенд ставит несколько хуков, каждый
  закрывает один способ обнаружения.
- **Цель (target)** — приложение, которое вы выбрали, чтобы скрыть VPN *от него*
  (банк, магазин), в отличие от VPN-клиента, который и есть скрываемое.
- **Роль (J / N / A / P)** — Java / Native / Apps / Ports, четыре вещи, которые
  можно включить для каждой цели. См. [Настроить скрытие](configure-hiding.md).
- **UID** — Linux-идентификатор пользователя, который Android присваивает каждому
  приложению. Скрытие применяется пер-UID — так одно приложение фильтруется, а
  система и ваш VPN-клиент нет.
- **Пакет (package)** — идентификатор приложения (например, `com.example.bank`).
  Роли хранятся по имени пакета.
- **Профиль** — отдельное пользовательское пространство на устройстве: основной
  профиль, **рабочий профиль**, **клон приложения** или Второе пространство.
  Ставьте VPN Hide только в основной профиль — см. [Рабочие профили](work-profiles.md).
- **GKI** — Generic Kernel Image от Google. Модуль ядра собирается под каждое
  GKI-поколение.
- **KMI** — Kernel Module Interface, тег (например, `android14-6.1`),
  обозначающий бинарный интерфейс ядра к модулям. По нему подбирают `.ko` — см.
  [Установка модуля ядра](kmod-install.md).
- **KernelPatch / SuperKey** — среда, нужная KPM, и ключ, которым APatch/FolkPatch
  авторизует его — см. [Установка бэкенда KPM](kpm-install.md).
- **Localhost / loopback** — собственный адрес устройства `127.0.0.1` / `::1`, где
  может слушать локальный прокси или VPN-демон. Роль **Ports** блокирует его
  пер-приложение.
- **Таблица маршрутизации / маршрут** — список ядра о том, куда идёт трафик; VPN
  добавляет маршрут через свой туннель, что может его выдать.
- **Раздельное туннелирование (split tunneling)** — выбор в VPN-клиенте, какие
  приложения идут через туннель, а какие напрямую — см.
  [Напрямую или через туннель](split-tunneling.md).
- **SELinux** — обязательный контроль доступа в Android. Если он в режиме
  Permissive, несколько способов обнаружения, закрываемых ядром, снова
  открываются — см. [Что означает каждый результат](check-result-meanings.md).
