# Значения результатов диагностики

- **Подтверждено** — проверены обязательный RAW-сигнал, защищённый ответ и контроли
  сохранности для данного вектора и записанного контекста.
- **Утечка** — защищённый worker видит тестовый сигнал. Незавершённые проверки
  других векторов не отменяют это доказательство.
- **Не проверено** — не хватает тестового сигнала, наблюдений, контролей или
  атрибуции. Пустой список или чистый Java-ответ сами по себе не доказывают скрытие.
- **Ошибка инфраструктуры** — Core не смог подготовить или завершить worker либо
  fixture. Прочитайте причину и нажмите **Повторить** после её устранения.
- **Очистка не завершена** — удаление тестовых ресурсов не подтверждено. Core
  сохраняет это состояние и блокирует небезопасное повторное использование.

## Сохранённые результаты

Предыдущие данные могут оставаться видимыми при потере связи, изменении настроек
или прерванном запуске. Учитывайте их актуальность и исходный контекст.
Восстановите связь с Core или разрешите неизвестный исход операции, прежде чем
считать данные текущими.

Включать VPN или добавлять VPN Hide в список split tunneling не требуется.
Доступность Dashboard от этих настроек не зависит. Результат свежего worker также
не подтверждает обновление старых процессов игр; перезапускайте цель после Save.

См. [Что проверяет диагностика](what-the-check-proves.md) и
[Сохранение и применение](saving-applying.md).
