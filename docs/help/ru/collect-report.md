# Собрать отчёт для диагностики

Откройте **Настройки → Отладка / Debugging**. Для проблемы с настройками или модулем
подойдёт снимок состояния, для ошибки во время работы другого приложения — запись.

## Снимок: что происходит сейчас

1. По возможности включите VPN и направьте через него сам VPN Hide, чтобы запустилась самопроверка.
2. Откройте **Debug export**, оставьте **Подробные логи / Verbose logs** включёнными.
3. Список установленных приложений и образ ядра оставьте выключенными, если их не попросили.
4. Выполните экспорт, затем сохраните или отправьте ZIP.

Экспорт доступен и без VPN либо без возможности выполнить самопроверку. Архив
фиксирует это ограничение и всё ещё полезен для разбора установки и доступа root.

## Запись: воспроизвести ошибку другого приложения

1. В **Настройки → Отладка / Debugging** нажмите **Start recording** до воспроизведения.
2. Переключитесь в приложение-цель, при необходимости остановите и откройте его заново,
   затем воспроизведите проблему.
3. Вернитесь в VPN Hide, остановите запись и сохраните или отправьте полученный файл.
4. В сообщении укажите ожидаемое и фактическое поведение, приложение и его версию,
   примерное время ошибки и шёл ли его трафик через VPN.

Экспорт временно включает логирование для собственного захвата и запускает
самопроверки. Он не восстановит подробные логи, выключенные в момент ошибки
приложения-цели. Перед свежей самопроверкой он также очищает буфер логов ядра:
последующий снимок не заменяет запись самого сбоя.

**Debug logging** в **Настройки → Developer** полезен, когда нужны непрерывные
логи вне захвата. Включайте его до воспроизведения и выключайте после завершения.
Захват восстанавливает состояние логирования, которое было до него.

## Проверьте содержимое перед отправкой

В ZIP находится `state.json`: конфигурация, состояния модулей, результаты проверок.
Подробный захват добавляет логи и сведения о сети и системе. Опция списка приложений
добавляет полный перечень и информацию о профилях. Если её выключить, имена настроенных
пакетов всё равно остаются в конфигурации, а сведения о приложениях и сети могут
попасть в логи. Архив может содержать информацию, позволяющую узнать ваше окружение.

Образ ядра — отдельное объёмное вложение для исследования ядра; добавляйте его только
по просьбе. Просмотрите файлы перед публичной публикацией и используйте ссылки для
связи в приложении, чтобы отправить отчёт через согласованный канал поддержки.
