# Собрать отчёт для диагностики

**Настройки → Отладка (Debugging) → Debug export** собирает один файл
(`vpnhide_debug_*.zip`) с диагностикой, по которой видно, что на самом деле делало
ваше устройство, — это гораздо полезнее описания словами.

## Как

1. Воспроизведите проблему: при включённом VPN холодно запустите целевое
   приложение, чтобы его проверки прошли снова.
2. Откройте **Настройки → Отладка (Debugging) → Debug export**.
3. Выберите, что включить. **Подробные логи** (dmesg, logcat, пробы) — обычно то,
   что нужно для баг-репорта. Список установленных приложений и образ ядра по
   умолчанию выключены — добавляйте их только по просьбе разработчика.
4. Нажмите **Export** и приложите ZIP в Telegram-группе или в issue на GitHub.

Если нужны непрерывные логи через холодный старт, сперва включите **Debug logging**
в **Настройки → Developer**, воспроизведите, затем экспортируйте. Захват в Debug
export включает логирование сам, так что обычно это не нужно — после выключите
обратно.

## Что внутри, а чего нет

В архиве — диагностический отчёт, состояния модулей и выбранные вами логи:
техническое состояние для диагностики скрытия, а не способ собрать персональные
данные. Список установленных приложений не попадает, пока вы его не включите.
Запись без VPN или когда VPN Hide не идёт через VPN — неполная, приложение об этом
предупреждает.
