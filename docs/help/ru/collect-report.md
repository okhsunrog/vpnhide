# Собрать отчёт для диагностики

Когда сообщаете о проблеме, диагностический архив позволяет автору увидеть, что
на самом деле делало ваше устройство, — это гораздо полезнее описания словами.

## Как

1. Включите **Debug logging** в **Диагностике** (или Настройки → Отладка). По
   умолчанию выключено. Обычные приложения не могут читать logcat, так что это не
   раскрывает вас.
2. Воспроизведите проблему: при включённом VPN холодно запустите целевое
   приложение, чтобы его проверки прошли снова.
3. В **Диагностике** нажмите **Экспорт**, чтобы собрать архив
   (`vpnhide_debug_*.zip`).
4. Приложите ZIP в [Telegram-группе или в issue на GitHub](vpnhide://diagnostics).
   После — выключите Debug logging обратно.

## Что внутри, а чего нет

В архиве — диагностический отчёт, состояния модулей и debug-лог: техническое
состояние, нужное для диагностики скрытия. Если сомневаетесь — просмотрите перед
отправкой; он для разбора проблемы, а не для сбора персональных данных. Запись без
VPN или когда VPN Hide не идёт через VPN — неполная; приложение об этом
предупреждает.
