# Отключение, сброс и удаление

## Приостановить скрытие для приложения

Снимите его роли на вкладке **Скрытие**, успешно сохраните, затем остановите и
откройте его заново. Это также уберёт хуки Zygisk из нового процесса. Простое
отключение модуля в root-менеджере не удаляет уже загруженные хуки: при изменении
установки или включения нужна перезагрузка. Сначала сделайте [копию конфигурации](config-backup.md),
если хотите позже восстановить выбор.

## Удалить установку и оставшиеся файлы

1. Экспортируйте конфигурацию, если она ещё понадобится.
2. Пока Core доступен, снимите роли и сохраните. Отключите VPN Hide в LSPosed.
3. Откройте **Настройки → Remove leftover files** и проверьте препятствия до
   удаления Core. Загруженным хукам может понадобиться выбранная вами перезагрузка
   или ядро без VPN Hide: удаление файла их не выгружает.
4. Выполняйте очистку только после подтверждения безопасности со стороны Core.
   Если эта бета не может достичь такого состояния, сохраните конфигурацию и Core
   и соберите отчёт; не удаляйте журнал и не обходите удержание неизвестного эффекта.
5. После завершённой очистки удалите **VPN Hide Core** через root-менеджер и
   удалите APK. Следуйте указаниям менеджера о перезагрузке.

В единой установке нет отдельного ZIP бэкенда для удаления. Старые модули требуют
явного пути миграции/восстановления. Очистка безвозвратно удаляет настройки;
удаление одного APK её не выполняет.

## Самостоятельно собранные ядра с Built-in

Эта расширенная интеграция не является обычным вариантом скачивания готового ядра,
и удалять у неё нечего: код встроен в работающее ядро. Для полной очистки нужно
**загрузить ядро без VPN Hide**, а также убрать остальные модули и отключить LSPosed. Повторная загрузка того же Built-in-ядра не снимет
блокировку очистки. До удаления самостоятельной интеграции продумайте возврат ядра.
