# Установка модуля Zygisk

Zygisk скрывает признаки VPN через libc-хуки внутри целевых процессов. Обе ABI
входят одной парой в полный Core ZIP. Используйте [установку Core](first-install.md);
отдельный ZIP VPN Hide Zygisk не нужен.

## Чего ожидать

Прямые системные вызовы могут обходить эти хуки, а приложения могут обнаруживать
изменения в собственном процессе. При выборе ролей учитывайте показанное Core
покрытие. Java/LSPosed предоставляет отдельный слой.

## Требования

Нужен совместимый провайдер Zygisk. Обнаружение payload, авторизация и реально
установленные хуки — отдельные факты. Само наличие LSPosed не доказывает
готовность payload VPN Hide.

## Шаги

1. Установите согласованные APK и универсальный Core ZIP.
2. Настройте необходимый провайдер и scope Java-слоя.
3. Перезагрузитесь, когда этого требует установка или состояние перехода Core,
   затем разблокируйте устройство.
4. Выберите роли целей и нажмите **Сохранить**.

Ожидание перезапуска или отсутствие подтверждения не означают активную защиту.
Следуйте указанию Дашборда и сохраняйте ошибки диагностики для обращения за помощью.

## Как применяются изменения

Уже запущенные приложения могут сохранить старую политику хуков. После изменения
конфигурации принудительно остановите и заново откройте цель. Изменение discovery
провайдера может требовать перезагрузки; перезапуск приложения сам по себе
обнаружение не гарантирует. Core владеет доставкой и авторизацией текущего boot;
файлы целей вручную не редактируются. Новый диагностический worker не доказывает,
что все старые процессы игр обновились.
