# Установка модуля Zygisk

Zygisk — это Native-бэкенд в пользовательском пространстве: он хукает libc
**внутри процесса каждого приложения-цели**. Берите его, когда ни один ядерный
бэкенд не подходит вашему устройству. Он слабее ядерных — сначала прочитайте
[Какой Native-бэкенд выбрать](choosing-native.md).

## Чего ожидать

- **Прямые вызовы `svc` его обходят.** Приложение, делающее системные вызовы
  напрямую, минуя libc, не фильтруется. У ядерных бэкендов (kmod / KPM) этого
  пробела нет.
- **Банковские и платёжные приложения могут его заметить.** Хуки живут в процессе
  самого приложения, и часть анти-тамперинга это замечает. Для таких приложений
  оставьте **Native выключенным** и полагайтесь на Java-слой — включение Native
  может насторожить их *сильнее*, а не наоборот. Дашборд показывает то же
  предупреждение.

Если ваше ядро тянет kmod или KPM, выбирайте их; Дашборд подскажет.

## Требования

- **Реализация Zygisk**: штатный Zygisk в Magisk либо ZygiskNext / NeoZygisk на
  Magisk или KernelSU.
- Включённый **LSPosed / Vector** для Java-слоя (тот же спутник нужен любому
  бэкенду).

## Шаги

1. Скачайте `vpnhide-zygisk.zip` (Дашборд назовёт файл).
2. В root-менеджере откройте **Modules → Install from storage** и выберите ZIP.
3. **Перезагрузитесь.**
4. Выберите приложения-цели в приложении VPN Hide.
5. Откройте **Дашборд**; Native-бэкенд должен показывать **Active**.

## Как применяются изменения

Хуки Zygisk ставятся при старте процесса приложения, поэтому изменение конфига
срабатывает при следующем свежем запуске. Сделайте приложению-цели **Force-stop**
(или перезагрузитесь) и откройте его заново — см.
[Настроить скрытие](configure-hiding.md).
