# Обновление приложения и модулей

VPN Hide — это приложение плюс модуль **VPN Hide Core** и один модуль нативного
бэкенда. Держите их версии **в ногу**: обновляете приложение — обновляйте и модули
core и бэкенда, а после перезагружайтесь. Приложение и core должны быть из одного
релиза: при несовпадении приложение показывает **«Версия VPN Hide Core не
совпадает»**, пока версии не сойдутся.

## Как обновлять

- **Приложение** — установите новый APK из релиза поверх старого.
- **Модуль** (core, модуль ядра, KPM, Zygisk) — установите новый ZIP через экран
  **Modules** своего root-менеджера (KernelSU / Magisk / APatch), затем
  **перезагрузитесь**.

## Обновление с 1.x

В 2.0 активаторы отдельных модулей заменил модуль core. Установите
`vpnhide-core.zip`, обновите ZIP нативного бэкенда, затем **удалите** старые модули
**VPN Hide (Ports)** и **VPN Hide (Built-in kernel)**, если они есть: в 2.0 таких
модулей нет, а их старые загрузочные скрипты мешают core (пока такой модуль
установлен, Дашборд показывает ошибку). Перезагрузитесь. Сохранённые роли
приложений сохранятся.

## Предупреждения о несовпадении версий

Дашборд сообщает, когда версии разъезжаются:

- *«Версия модуля X старше версии приложения Y»* — обновите этот модуль (откройте
  root-менеджер → Modules).
- *«Версия модуля X новее версии приложения Y»* — обновите приложение VPN Hide.

Следуйте предупреждению для конкретного компонента. Маленькая разница в номерах
сама по себе не доказывает, что несовпадение безвредно.

## Перестало работать сразу после обновления системы

Обновление системы или ядра может изменить ядро так, что `.ko` перестанет
загружаться (сместился его GKI-интерфейс), либо сбросить ваш scope в LSPosed. Это
отдельная ситуация со своими решениями — см.
[Перестало работать после обновления](broke-after-update.md).

## После обновления APK тоже нужна перезагрузка

После замены APK процесс приложения может быть новым, а код LSPosed, уже загруженный
в `system_server`, остаётся старым. Перезагрузитесь, даже если обновили только APK.
Затем проверьте на Дашборде версии работающих компонентов и ошибки применения.
Перезагрузка не обновит старый ZIP, который вы не заменили.

По возможности используйте компоненты [одного официального релиза](https://github.com/okhsunrog/vpnhide/releases).
При самостоятельной Built-in-интеграции замена APK или модуля core не заменяет код ядра:
свою интеграцию ядра обновляйте отдельно.
