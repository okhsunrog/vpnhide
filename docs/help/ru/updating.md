# Обновление приложения и модулей

VPN Hide — это приложение плюс один или несколько модулей (Native-бэкенд и,
возможно, Ports). Держите их версии **в ногу**: обновляете приложение —
обновляйте и модули, а после перезагружайтесь.

## Как обновлять

- **Приложение** — установите новый APK из релиза поверх старого.
- **Модуль** (модуль ядра, KPM, Zygisk, Ports) — установите новый ZIP через экран
  **Modules** своего root-менеджера (KernelSU / Magisk / APatch), затем
  **перезагрузитесь**.

## Предупреждения о несовпадении версий

Дашборд сообщает, когда версии разъезжаются:

- *«Версия модуля X старше версии приложения Y»* — обновите этот модуль (откройте
  root-менеджер → Modules).
- *«Версия модуля X новее версии приложения Y»* — обновите приложение VPN Hide.

Точного совпадения до цифры не требуется, но большой разрыв значит, что одна из
половин устарела; сведите их вместе.

## Перестало работать сразу после обновления системы

Обновление системы или ядра может изменить ядро так, что `.ko` перестанет
загружаться (сместился его GKI-интерфейс), либо сбросить ваш scope в LSPosed. Это
отдельная ситуация со своими решениями — см.
[Перестало работать после обновления](broke-after-update.md).
