# Обновление приложения и модулей

VPN Hide использует APK и один полный ZIP **VPN Hide Core**. Core содержит
нативные компоненты и выбирает подходящий бэкенд. Используйте совместимые артефакты
[одного официального релиза](https://github.com/okhsunrog/vpnhide/releases).
Жизненный цикл публикации Zygisk в этой бете ещё пересматривается: состав архива
сам по себе не доказывает готовность бэкенда.

## Как обновлять

- Установите новый APK поверх старого.
- Для обновления Core установите **полный ZIP Core** через раздел Modules
  root-менеджера, затем перезагрузитесь для активации подготовленной замены.
- Проверьте совместимость и версии работающих компонентов на Дашборде.

Совместимое обновление только клиентского интерфейса APK само по себе не требует
переустановки Core. Отдельный ZIP kmod, KPM или Zygisk и ручной выбор GKI не нужны.

## Обновление с 1.x

Сначала подготовьте и проверьте замену, сохранив настройки. Только затем
удаляйте старые модули по инструкции миграции полного пакета Core. Модули
Ports/Built-in и загрузочные скрипты отдельных бэкендов относятся к прежней
схеме; до их удаления новая замена должна быть готова. Общий автоматический
процесс обслуживания в этой бете ещё реализуется.

## Предупреждения о несовпадении версий

Следуйте предупреждению для конкретного работающего компонента. Проверяйте
совместимость протокола APK/Core и фактически загруженное поколение: близкие
номера версий сами по себе ничего не гарантируют. Изменение версии RPC или
журнала Core само по себе не требует пересборки своего Built-in ядра.

## Перестало работать сразу после обновления системы

Обновление ядра может изменить совместимость модулей или scope LSPosed.
Core определяет кандидатов по проверенному каталогу. Сохраните сведения об ошибке
и откройте [Перестало работать после обновления](broke-after-update.md);
не перебирайте произвольные архивы бэкендов.

## После обновления APK тоже нужна перезагрузка

Перезагрузка нужна, когда изменённый код LSPosed должен заменить код, уже
загруженный в `system_server`. У совместимого обновления только клиентского
интерфейса APK другой жизненный цикл. Проверьте работающую версию и требуемое
действие. Перезагрузка не заменит старый пакет Core, который вы не обновили.

Собственная Built-in-интеграция — это код ядра: замена APK или ZIP Core её
не заменяет.

## Обновление через приложение

При актуальном совместимом соединении с Core и наличии проверенного целевого
пакета в APK Dashboard предлагает **Выбрать ZIP обновления Core**. Выберите
соответствующий полный Core ZIP. Core проверяет подпись, точные байты пакета и
подготовленный образ, прежде чем сообщить о необходимости перезагрузки.
Перезагрузку запускаете вы; приложение никогда не перезагружает телефон само.
Подготовленное обновление ещё не является запущенным Core. Если подтверждение
потеряно, проверьте состояние той же операции вместо повторной установки.
Неподписанные сборки для разработки без настроенного доверия не предлагают это действие.

Если Core отсутствует или версии APK/Core RPC несовместимы, используйте экран
модулей root-менеджера, как описано выше. Приложение не запускает su-установщик.
Единый bootstrap/handoff при отсутствии Core ещё реализуется.
