# Требования и совместимость

VPN Hide требует **root** для своего модуля core (самому приложению root-доступ не нужен). Включайте слои под способы обнаружения у вашей цели.
Обычная отправная точка — Java + Native, но использование только части слоёв допустимо.

| Компонент | Требует |
|---|---|
| Приложение | Android 9+, arm64 или armv7; релизная сборка в основном пользователе (сборка `.dev` и копия во вторичном пользователе до core не достучатся) |
| Core | Модуль **VPN Hide Core** (`vpnhide-core.zip`, из того же релиза, что и приложение) установлен и включён в Magisk, KernelSU или APatch |
| Роли Java и Apps | LSPosed / LSPosed-Next / Vector; VPN Hide включён для System Framework |
| Native — kmod | Совместимое arm64 GKI-ядро с нужной поддержкой проб; следуйте рекомендации Дашборда |
| Native — KPM | Поддерживаемое семейство arm64-ядра и среда KernelPatch, например APatch или KPatch-Next |
| Native — Zygisk | Работающая реализация Zygisk: например, Magisk Zygisk либо ZygiskNext/NeoZygisk |
| Ports | Ничего дополнительно: входит в модуль core |

Ядерные бэкенды работают только на arm64. Если совместимого ядерного бэкенда нет,
[Zygisk](zygisk-install.md) — запасной вариант с меньшим покрытием. Сам KernelSU
не предоставляет реализацию Zygisk, необходимую этому бэкенду.

**Предпочтителен совместимый ядерный бэкенд.** Хуки Zygisk работают внутри
процессов приложений. Банковские, антифрод- и другие защищённые приложения могут
обнаружить провайдер или внедрённый код и отказаться работать. Zygisk — запасной
вариант с меньшим покрытием, а не рекомендуемая отправная точка. Ядерный бэкенд
не гарантирует незаметность и не скрывает установленный провайдер Zygisk или root.
Прямые системные вызовы могут обходить libc-хуки.

## Что устанавливать

Начните с [Первой установки](first-install.md) и [описания выбора Native-бэкенда в Core](choosing-native.md).
Ядерные хуки не внедряют libc-хуки в процесс цели, но не обещают невидимость для любых
проверок целостности или root. VPN Hide не скрывает root и не обеспечивает прохождение Play Integrity.

Built-in — расширенная интеграция для **самостоятельной сборки ядра**, а не поддерживаемая
загрузка готового ядра. См. отдельное пояснение в [Выборе Native](choosing-native.md).
