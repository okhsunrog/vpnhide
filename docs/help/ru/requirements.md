# Требования и совместимость

VPN Hide — это набор root-модулей плюс это приложение. Нужен root и хотя бы
Java-слой; нативный слой требует совместимого ядра или KernelPatch-рантайма.

## Что нужно

| Компонент | Требует |
|---|---|
| Приложение (пикер) | Android 9+, arm64 или armv7 |
| Java-слой | LSPosed, LSPosed-Next или Vector |
| Native — kmod | GKI-ядро с `CONFIG_KPROBES` (стандарт на Android 12+) |
| Native — KPM | APatch или KPatch-Next-Module (KernelPatch-рантайм) |
| Native — Zygisk | Zygisk (Magisk / KernelSU) или ZygiskNext |
| Ports (опционально) | любой root-менеджер |

Ставится **один** нативный бэкенд, Java-слой и, по желанию, Ports. Само
приложение работает и на 32-битных (armv7) устройствах, но kernel-бэкенды —
только arm64.

## Как выбрать нативный бэкенд

По возможности берите kernel-бэкенд — `kmod` или встроенный патч ядра — если
устройство его поддерживает: они перехватывают в пространстве ядра, и банковские
и платёжные приложения их не видят. `Zygisk` работает везде, где есть Zygisk, но
часть таких приложений замечает его хуки внутри процесса. На дашборде есть
рекомендация бэкенда под ваше устройство.
