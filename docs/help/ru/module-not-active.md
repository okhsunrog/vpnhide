# Модуль установлен, но не активен

На дашборде видно состояние каждого модуля. «Установлен, но не активен» почти
всегда имеет одну из нескольких конкретных причин — сообщение на экране называет
точную.

## Частые причины

- **Перезагрузите для активации.** Только что установленный нативный модуль
  загрузится лишь после перезагрузки. Перезагрузите устройство.
- **Не добавлен scope в LSPosed.** Java-слою нужен **System Framework** в scope
  VPN Hide. Добавьте его в LSPosed / Vector и перезагрузитесь.
- **Два нативных бэкенда сразу.** Модуль ядра и KPM перехватывают одни и те же
  функции ядра; оставьте только один. Два сразу могут даже заморозить устройство
  — удалите один.
- **KPM без SuperKey.** APatch/FolkPatch не смог загрузить KPM доверенным токеном.
  Сохраните SuperKey в **Настройки → Безопасность** и перезагрузитесь.
- **Битая установка.** «Активатор отсутствует / не исполняемый» означает, что ZIP
  установился некорректно. Переустановите полный ZIP из последнего релиза через
  экран Модули в root-менеджере — не распаковывайте внутренний файл.
- **Неподдерживаемое ядро.** У KPM нет проверенных смещений для этого семейства
  ядер. Используйте бэкенд Zygisk.

Что бы ни писало сообщение — выполните указанное действие, затем нажмите
**Обновить** (или перезагрузитесь, когда просит). Если всё равно не активируется —
соберите [отчёт для диагностики](collect-report.md).
