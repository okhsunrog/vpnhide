# Модуль установлен, но не активен

На дашборде видно состояние каждого модуля. «Установлен, но не активен» почти
всегда имеет одну из нескольких конкретных причин — сообщение на экране называет
точную.

## Частые причины

- **Нет среды KernelPatch.** Сообщение «ядро не пропатчено» означает, что VPN Hide не обнаружил работающую среду для KPM. Установка `vpnhide-kpm.zip` её не добавляет. См. [где скачать KPatch-Next-Module и как установить среду](kpm-install.md).
- **Нет VPN Hide Core.** Любой бэкенд загружает модуль core (`vpnhide-core.zip`).
  Без него ничего не загружается, а при запуске приложение показывает **«VPN Hide
  Core не запущен»**. Установите его из того же релиза и перезагрузитесь.
- **Перезагрузите для активации.** Только что установленный нативный модуль
  загрузится лишь после перезагрузки: core выбирает и загружает бэкенд один раз за
  загрузку. Перезагрузите устройство.
- **Не добавлен scope в LSPosed.** Java-слою нужен **System Framework** в scope
  VPN Hide. Добавьте его в LSPosed / Vector и перезагрузитесь.
- **Больше одного нативного бэкенда.** Core загружает бэкенд, только если он
  единственный: при двух установленных (или одном установленном на ядре со
  встроенным VPN Hide) он не загружает **ни один**, а Дашборд их перечисляет.
  Удалите лишние и перезагрузитесь.
- **KPM без SuperKey.** APatch/FolkPatch не смог загрузить KPM доверенным токеном.
  Сохраните SuperKey в **Настройки → Безопасность** — core загрузит ожидающий KPM
  без перезагрузки.
- **Устаревший модуль 1.x.** Всё ещё установлен модуль **VPN Hide (Ports)** или
  **VPN Hide (Built-in kernel)** из 1.x. В 2.0 оба заменены модулем core, а их
  старые загрузочные скрипты ему мешают: удалите модуль и перезагрузитесь.
- **Битая установка.** Отсутствующая полезная нагрузка (`.ko`, `.kpm` или
  библиотека Zygisk) означает, что ZIP установился некорректно. Переустановите полный ZIP из последнего релиза через
  экран Модули в root-менеджере — не распаковывайте внутренний файл.
- **Неподдерживаемое ядро.** У KPM нет проверенных смещений для этого семейства
  ядер. Используйте бэкенд Zygisk.

Что бы ни писало сообщение — выполните указанное действие, затем нажмите
**Обновить** (или перезагрузитесь, когда просит). Если всё равно не активируется —
соберите [отчёт для диагностики](collect-report.md).
