# Установка модуля ядра

Модуль ядра (`.ko`, на Дашборде — **Kmod**) — это Native-бэкенд по умолчанию на
GKI-ядрах. Хуки стоят в пространстве ядра, поэтому память процесса
приложения-цели не затрагивается libc-хуками. Это устраняет именно этот способ
обнаружения вмешательства в процесс, но не скрывает root и не гарантирует работу любого приложения.
Сначала убедитесь, что это подходящий бэкенд для вашего устройства — см.
[Какой Native-бэкенд выбрать](choosing-native.md).

## Подберите GKI-версию

`.ko` собирается под каждое **GKI-поколение**. Ставить нужно ZIP, который
соответствует тегу KMI (Kernel Module Interface) вашего ядра — например,
`android14-6.1`. Этот тег входит в строку версии ядра; он обозначает бинарный
интерфейс ядра к модулям, а **не** версию вашей Android-системы, так что
«android14» в теге не значит, что у вас Android 14.

**Дашборд** прочитает ядро и укажет точный файл для загрузки (например,
`vpnhide-kmod-android14-6.1.zip`). Если по строке версии он не может однозначно
определить GKI-ветку, он назовёт один вариант «попробуйте сначала» и запасной —
на случай, если первый не загрузится.

## Шаги

1. Скачайте ZIP, который назвал Дашборд.
2. В своём root-менеджере (Magisk / KernelSU / APatch) откройте **Modules →
   Install from storage** и выберите ZIP.
3. **Перезагрузитесь** — модуль загружается при старте.
4. Откройте **Дашборд**; Native-бэкенд должен показывать **Active**.

Цели выбираются в приложении VPN Hide; никакие файлы вручную править не нужно.

## Обновление и удаление

Загруженный `.ko` остаётся в памяти до перезагрузки. Чтобы обновить или удалить
его, сделайте это на экране **Modules** своего root-менеджера (обновите ZIP или
отключите модуль) и **перезагрузитесь**, чтобы изменение вступило в силу. Обычный
`rmmod` не поддерживается.

## Если не загружается

Дашборд сообщает, какой именно случай:

- **Installed, wrong GKI variant** — вы прошили ZIP от другого поколения.
  Поставьте тот, что называет Дашборд.
- **Installed, did not load — try the other GKI variant** — GKI-ветка оказалась
  неоднозначной; поставьте запасной вариант, предложенный Дашбордом.
- **Installed, kernel not supported** / **kernel has no kprobes** — это ядро не
  может загрузить `.ko`. Используйте [бэкенд KPM](kpm-install.md), если ваше
  семейство ядра поддерживается, иначе [модуль Zygisk](zygisk-install.md).
- **Installed, kernel rejects unsigned modules** — включена проверка подписи
  модулей, и `.ko` не вставить. Используйте KPM (он загружается через
  KernelPatch, а не через загрузчик модулей) или Zygisk.

Если модуль загрузился, но Дашборд показывает, что встали лишь часть хуков, — на
этом конкретном ядре несколько способов обнаружения этот бэкенд не закрывает;
переустановка это не изменит. См.
[Модуль установлен, но не активен](module-not-active.md).
