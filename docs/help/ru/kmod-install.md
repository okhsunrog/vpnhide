# Установка модуля ядра

Этот бэкенд работает в ядре. Его payload входят в полный Core ZIP; используйте
[единую установку Core](first-install.md).

## Подберите GKI-версию

Core определяет совместимые варианты по проверенному каталогу payload и данным
ядра. KMI вроде `android14-6.1` обозначает интерфейс модуля ядра, а не версию
Android на телефоне. Вручную выбирать GKI или пробовать разные ZIP не требуется.
Неоднозначное или неподдерживаемое ядро не считается совместимым.

## Шаги

1. Установите APK и полный `vpnhide-core.zip` из одного релиза/сборки.
2. Перезагрузите и разблокируйте устройство.
3. Проверьте Дашборд, выберите роли приложений и нажмите **Сохранить**.

Core загружает и настраивает выбранный бэкенд. Если выбор не завершён, следуйте
его указаниям по восстановлению или перезапуску.

## Обновление и удаление

Обновляйте согласованную пару APK/Core. Загруженный `.ko` остаётся в ядре до
перезагрузки; обычный `rmmod` не поддерживается. Удаление Core затрагивает весь
сервис. Сохраняйте рабочую установку до проверки замены.

## Если не загружается

Загрузка может быть недоступна из-за проверки подписей модулей, отсутствующих
возможностей ядра, неоднозначной совместимости или неполных хуков. Core сообщает
причину и оценивает допустимые варианты без урезания политики. Ошибка или
неизвестный результат не разрешают пробовать другой payload вручную.
См. [KPM](kpm-install.md), [Zygisk](zygisk-install.md) и
[сбор отчёта](collect-report.md).
