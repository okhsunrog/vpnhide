# Когда применяются изменения

Выбрав роли на вкладке **Скрытие**, нажмите **Сохранить** и дождитесь результата.
Затем принудительно остановите приложение-цель в настройках Android и откройте
снова: оно может помнить старый результат обнаружения даже после применения скрытия.

## «Сохранено» не всегда означает «применено»

- **Успех:** конфигурация сохранена, запрошенные этапы применения выполнены.
- **Сохранено, но применение не удалось:** выбор записан, но часть слоёв может
  продолжать использовать прежние настройки. Прочитайте ошибку, устраните причину
  (например, отсутствие root или модуля) и воспользуйтесь предложенным повторным применением.
- **Результат неизвестен / изменения приостановлены:** VPN Hide не смог подтвердить,
  чем закончилась предыдущая операция. Нажмите **Проверить снова / Check again**.
  Не пытайтесь обойти это повторными импортами или переключениями. Если повторная
  проверка не помогает, [соберите отчёт](collect-report.md).
- **Несохранённые изменения:** выбор в списке — черновик до успешного сохранения.
  **Отменить изменения / Discard edits** возвращает сохранённый выбор. При сообщении
  о конфликте ознакомьтесь с обновлённой конфигурацией и повторите нужные изменения.

## Перезапустить приложение или телефон?

| Что изменилось | Что сделать |
|---|---|
| Роли Java / Apps, цели и хуки ядерного Native | Успешно сохранить; остановить приложение-цель, чтобы сбросить его кеш |
| Цели и хуки Zygisk | Сохранить, остановить и открыть приложение-цель: хуки ставятся при старте процесса |
| Цели и диапазоны Ports | Успешно сохранить; правила меняются без перезагрузки |
| Установка, обновление, включение или удаление модуля | Перезагрузить телефон для завершения операции root-менеджера |
| Установка или обновление APK VPN Hide, изменение scope или включения в LSPosed | Перезагрузить телефон: загруженные в `system_server` хуки продолжают работать до перезагрузки |
| Экспериментальное скрытие путей на ядерном бэкенде | Перезагрузить телефон; следовать сообщению об ожидающем изменении |
| Экспериментальное скрытие путей на Zygisk | Перезапустить выбранные приложения |

Технически Save запускает активатор для передачи конфигурации, а не выгружает и
заново запускает ядерный бэкенд. Активатор превращает сохранённую конфигурацию
в то, что читает каждый бэкенд: ядерные бэкенды получают её сразу, модуль Zygisk
читает свой файл `targets.txt` при каждом запуске процесса приложения-цели,
правила Ports применяются заново. Эти рабочие файлы также пересобираются при
каждой загрузке телефона и один раз при каждом запуске VPN Hide с нуля, поэтому
надолго разойтись с сохранённой конфигурацией они не могут. Приложения в них
перечислены по UID, а не по имени: если переустановить приложение-цель, оно
может получить новый UID, поэтому перед force-stop нажмите Save ещё раз
(перезагрузка телефона или запуск VPN Hide с нуля дают тот же эффект).

## Обновление Дашборда

VPN Hide обновляет состояние при возвращении в приложение. Если Дашборд всё ещё
показывает прежнее состояние VPN, нажмите **Повторить / Retry** для свежей проверки.
Один перезапуск приложения-цели не обновляет и не доказывает его скрытие;
см. [Что проверяет самопроверка](what-the-check-proves.md).
