# Первая установка

Установите APK VPN Hide и **один полный Core ZIP из одного релиза/сборки**.
Core содержит нативные варианты и Ports. Для Java/Apps также нужен LSPosed или
совместимая реализация. См. [Требования и совместимость](requirements.md).

## Шаги

1. **Установите приложение** из согласованной поставки.
2. **Установите `vpnhide-core.zip`** через экран «Модули» root-менеджера и оставьте
   Core включённым. APK общается с Core и сам не запрашивает root.
3. **Core выберет Native автоматически.** Payload входят в универсальный ZIP.
   См. [выбор бэкенда](choosing-native.md) и [требования KPM](kpm-install.md).
4. **Включите Java-слой** в LSPosed / Vector и добавьте **System Framework**
   в scope VPN Hide.
5. **Ports необязателен:** назначьте эту роль приложениям позже; он входит в Core.
6. **Перезагрузите и разблокируйте** устройство.

При обновлении сохраните конфигурацию и рабочую установку до подготовки и
проверки замены. Для старых отдельных модулей следуйте указаниям миграции Core.

## Проверка

Откройте Дашборд и проверьте готовность Core и сохранённую диагностику. Они не
зависят от включения внешнего VPN и включения APK в его split-tunnel список.
Ожидание, ошибка и неполные доказательства не являются успешной проверкой защиты.
Затем перейдите к [первому приложению](first-setup.md), выберите роли и нажмите
**Сохранить**.

## Официальные загрузки

Используйте согласованные APK и полный `vpnhide-core.zip` из
[релизов проекта](https://github.com/okhsunrog/vpnhide/releases) или предоставленной
сборки. Базовый архив только с daemon — внутренний результат сборки, а не полный
установщик.
