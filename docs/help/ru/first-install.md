# Первая установка

VPN Hide — это несколько частей, работающих вместе: это приложение (пикер), один
**нативный** бэкенд, слой **Java** через LSPosed и необязательный модуль
**Ports**. Сначала сверьтесь с [Требованиями и совместимостью](requirements.md).

## Шаги

1. **Установите приложение** — APK пикера из релизов проекта. Это и есть дашборд,
   в котором вы читаете эту справку.
2. **Выдайте ему root.** VPN Hide нужен root, чтобы управлять скрытием. Откройте
   приложение и подтвердите запрос в своём root-менеджере (Magisk / KernelSU /
   APatch). Если пропустили запрос — приложение покажет экран **Root access
   required**; выдайте доступ и нажмите **Check again**.
2. **Установите один нативный бэкенд.** На дашборде есть рекомендация под ваше
   устройство. Ставьте его модуль (ZIP) через экран **Модули** в root-менеджере —
   Magisk, KernelSU, APatch или FolkPatch. Ставьте только один нативный бэкенд:
   два активных сразу могут конфликтовать.
3. **Включите Java-слой.** В LSPosed / LSPosed-Next / Vector включите **VPN Hide**
   и добавьте в его scope **System Framework**. Без этого scope Java-хуки не
   подцепятся.
4. **(Опционально) Установите Ports**, если нужно скрытие localhost-портов.
5. **Перезагрузитесь**, чтобы нативные и Java-модули загрузились.

## Проверка

Откройте **Дашборд**. Каждый установленный модуль должен показывать **Active**, а
шапка — **VPN скрыт**, когда VPN включён и его проверки прошли. Если модуль пишет
«перезагрузите для активации» или «не активен» — следуйте подсказке на экране.
Обычные причины: не добавлен scope, модуль без перезагрузки, или два нативных
бэкенда сразу.
