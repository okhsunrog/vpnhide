# Первая установка

VPN Hide — это несколько частей, работающих вместе: это приложение (пикер), модуль
**VPN Hide Core**, который выполняет всю работу с root, один **нативный** бэкенд и
слой **Java** через LSPosed. Скрытие localhost-портов (**Ports**) входит в модуль core. Сначала сверьтесь с [Требованиями и совместимостью](requirements.md).

Ниже описана рекомендуемая установка Java + Native. Можно пропустить слой, но его
способы обнаружения останутся непокрытыми; Ports необязателен. См. [Требования](requirements.md).

## Шаги

1. **Установите приложение** — APK пикера из релизов проекта. Это и есть дашборд,
   в котором вы читаете эту справку.
2. **Установите модуль core.** Поставьте `vpnhide-core.zip` из **того же релиза**,
   что и приложение, через экран **Модули** root-менеджера (Magisk / KernelSU /
   APatch) и не отключайте его. Само приложение root не запрашивает — оно
   общается с модулем core. Пока core не запущен (до перезагрузки на шаге 6),
   приложение показывает **«VPN Hide Core не запущен»**; core из другого релиза —
   **«Версия VPN Hide Core не совпадает»**. Обновляетесь с 1.x? Удалите старые
   модули **VPN Hide (Ports)** и **VPN Hide (Built-in kernel)**, если они есть.
3. **Установите один нативный бэкенд.** На дашборде есть рекомендация под ваше
   устройство. Ставьте его модуль (ZIP) через экран **Модули** в root-менеджере —
   Magisk, KernelSU, APatch или FolkPatch. Ставьте только один нативный бэкенд:
   если их больше одного, core не загрузит ни один.
   Инструкции: [kmod](kmod-install.md) · [KPM и установка KernelPatch](kpm-install.md) ·
   [Zygisk](zygisk-install.md). Если не уверены — [выбор бэкенда](choosing-native.md),
   включая вариант для ядра со встроенным VPN Hide.
4. **Включите Java-слой.** В LSPosed / LSPosed-Next / Vector включите **VPN Hide**
   и добавьте в его scope **System Framework**. Без этого scope Java-хуки не
   подцепятся.
5. **(Опционально) [Ports](ports.md)** — ставить ничего не нужно, позже просто дайте приложениям роль Ports.
6. **Перезагрузитесь**, чтобы запустился core, загрузил нативный бэкенд и подключился Java-слой.

## Проверка

Откройте **Дашборд**. Каждый установленный модуль должен показывать **Active**, а
шапка — **VPN скрыт**, когда VPN включён и его проверки прошли. Если модуль пишет
«перезагрузите для активации» или «не активен» — следуйте подсказке на экране.
Обычные причины: не добавлен scope, модуль без перезагрузки, не установлен модуль
core или два нативных бэкенда сразу.

Дальше — [Настроить скрытие](configure-hiding.md).

## Официальные загрузки

Берите APK, `vpnhide-core.zip` и ZIP бэкендов из [релизов проекта](https://github.com/okhsunrog/vpnhide/releases). Выбирайте Native ZIP, рекомендованный для вашего устройства: ZIP ядра не универсален для всех телефонов.
