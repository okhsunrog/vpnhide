# 模块已安装但未生效

仪表盘分别显示磁盘文件、后端选择、已确认的应用结果和测量到的保护情况。
请按当前具体错误处理。

## 常见原因

- **Core 缺失或不兼容：**安装完整 Core ZIP 和配套 APK。
- **等待重启：**完成所提示的重启并解锁。提供程序可能仍保留旧 payload，直到其生命周期边界。
- **Java 作用域缺失：**在 LSPosed / Vector 中启用 VPN Hide 和 System Framework。
- **KernelPatch 不可用或认证失败：**见[KPM 要求](kpm-install.md)。
- **旧独立模块或自行加载的后端：**按迁移提示操作；移除旧安装前保留配置并验证替代安装。
- **payload 缺失或损坏：**使用完整配套 Core 安装器。
- **内核不支持或检查不完整：**猜测 GKI 版本、重装独立后端 ZIP 或开启外部 VPN 都无法解决。

Core 中的候选实现本来就应一起存在，仅有这些文件不会构成冲突。
问题仍存在时，[收集报告](collect-report.md)。
