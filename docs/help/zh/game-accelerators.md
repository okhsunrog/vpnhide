# 游戏加速器

游戏加速器——UU、迅游、腾讯、Biubiu 等——本身就是一个 VPN。在 Android 上它会建立一个
VpnService 隧道，把你选定的游戏导入其中，于是系统会看到一个活动的 VPN 和一个已安装的
VPN 应用，其他应用可能因此有所反应。

## 把加速器的 VPN 对另一个应用隐藏

如果在加速器开启时，银行或其他应用「因为有 VPN」而拒绝运行：

- 给**那个**应用开启 **Java + Native** 隐藏网络信号，并开启 **Apps** 隐藏软件包。
- 把加速器加入隐藏 VPN 应用名单（**设置 → 隐藏 VPN 应用**，或[立即打开](vpnhide://hidden-apps)），
  让软件包扫描发现不了它。

由于加速器只代理你选定的游戏，你要隐藏的那个应用本来就不在隧道里——把 VPN 对它隐藏
不会改变它的联网。

## 为什么自检无法运行

加速器可能只允许固定的游戏列表。Core 诊断无需把 VPN Hide 加入该列表：它使用自己的有界测试
对象，独立于加速器的路由以及 VPN 是否开启。请在[诊断](vpnhide://diagnostics)中查看已记录的
范围与缺失证据。新工作进程的结果不能证明正在运行的游戏已采用相同配置。

## 这不是什么

这里说的是把加速器的 VPN 对*其他*应用隐藏。把它对你正在加速的那款游戏隐藏、以绕过该
游戏自身的反作弊，是另一回事：可能违反游戏规则并导致封号，而且对内核级反作弊，VPN Hide
无法保证任何效果。

返回[设置隐藏](configure-hiding.md)。
