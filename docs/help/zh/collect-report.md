# 收集调试报告

打开 **设置 → Debugging**。配置或模块问题可用状态快照；在另一个应用中出现的问题
应使用录制来捕获。

## 快照：查看当前状态

1. 如果可以，开启 VPN 并让 VPN Hide 走隧道，以便运行自检。
2. 打开 **Debug export**，为诊断报告保留 **Verbose logs** 开启。
3. 除非被要求，否则不要启用已安装应用列表或内核镜像。
4. 导出，然后保存或分享 ZIP。

VPN 关闭或自检无法运行时仍能导出。调试包会记录这一限制，仍可用于调查安装和 root 问题。

## 录制：复现另一个应用的问题

1. 在 **设置 → Debugging** 中先点 **Start recording**。
2. 切换到目标应用，必要时强制停止并重新打开，然后复现问题。
3. 返回 VPN Hide，停止录制，再保存或分享文件。
4. 描述预期行为、实际行为、目标应用及版本、故障的大致时间，以及它是否走 VPN 隧道。

调试导出只会为自身采集临时开启日志，并运行自检。它无法补回目标应用出错时未启用的
详细日志。它还会在采集新的自检窗口前清空内核日志缓冲区；事后的快照不能替代故障录制。

需要在采集之外持续记录时，可先开启 **设置 → 开发者 → Debug logging**，复现后
再关闭。采集结束会恢复采集前的日志开关状态。

## 分享前检查内容

ZIP 包含 `state.json`，其中有配置、模块状态及诊断结果。详细采集还包含日志和网络、
系统信息。应用列表选项增加完整清单和资料信息；关闭它并**不**会移除配置中的目标包名，
也不保证日志中没有应用或网络信息。请将报告视为可能包含可识别环境信息的文件。

内核镜像是用于内核调查的独立大型附件，仅在被要求时添加。公开发布前检查文件内容，
通过应用内的联系方式使用约定的支持渠道分享。
