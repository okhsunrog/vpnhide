# 收集调试报告

当你反馈问题时，一份调试包能让作者看到你的设备实际做了什么——比纯文字描述有用得多。

## 怎么做

1. 在**诊断**里打开 **Debug logging**（或设置 → 调试）。默认关闭。普通应用读不到
   logcat，所以这不会暴露你。
2. 复现问题：在 VPN 开启的情况下，冷启动目标应用，让它的检查重新运行。
3. 在**诊断**里点**导出**，生成调试包（`vpnhide_debug_*.zip`）。
4. 把 ZIP 发到 [Telegram 群或 GitHub issue](vpnhide://diagnostics)。之后把 Debug
   logging 关回去。

## 里面有什么、没有什么

调试包包含诊断报告、模块状态和调试日志——诊断隐藏所需的技术状态。不确定的话，发送前先
看一眼；它是用于排查问题的，不是用来收集个人数据的。在没有 VPN、或 VPN Hide 没走这条
VPN 时采集的记录是不完整的；应用会在这种情况下提示你。
