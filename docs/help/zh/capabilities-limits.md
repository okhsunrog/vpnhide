# 能做到与做不到什么

## 能做到

把 VPN 在*设备上的迹象*对你选定的应用隐藏起来——应用通过 Java API、内核和 libc 读到
的网络信号；已安装的 VPN 客户端的存在；以及本地回环上的 VPN/代理端口。不同应用探测
不同的东西，VPN Hide 对每种都有一个角色：**Java**、**Native**、**Apps**、**Ports**。

## 做不到

- **改变你的外部 IP。** 服务器看到的是 VPN 的出口 IP。在服务器端运行、或按 IP 判断的
  反欺诈与地理检测在手机之外——设备无法隐藏它。
- **绕过服务器端或账号级检测。** 如果某服务在它自己的后端判定你在用 VPN，设备上的
  隐藏改变不了这个结论。
- **隐藏你已 root 或在用自定义 ROM，或让应用通过 Play Integrity。** VPN Hide 只隐藏
  VPN，别无其他。若某应用因检测到 root 或通不过完整性认证而拒绝，那是另一码事，不是
  本工具要做的。
- **无 root 运行。** 必须有 root。Java/Apps 需要 LSPosed，Native 需要原生后端，
  Ports 需要对应模块。可以少用一些层，但覆盖会减少。
- **对无限多的应用启用 Native。** 原生后端最多保护 **159 个应用 UID**（按 UID 计数而
  非应用数，并为 VPN Hide 自身保留一个名额）。选择器会阻止超出 UID 预算的选择或保存；
  提示达到上限时请减少 Native 目标。导入配置或新增资料也可能超出运行时容量；不要忽略
  应用/容量警告，也不要认为所有已保存目标都已受保护。被克隆到工作资料或第二空间的应用会占用两个名额——见
  [工作资料](work-profiles.md)。Java 和 Apps 角色不受此上限限制。
- **击败游戏自身的反作弊。** 把 VPN 对你正在玩的那款游戏隐藏、以绕过它的检查，是另一
  回事，VPN Hide 并不保证——见[游戏加速器](game-accelerators.md)。

## 路由是独立选择

目标可在隧道内或外。VPN Hide 改变本地视图，不改变 VPN 客户端的路由规则或公网 IP。
从所需角色开始，检查目标的实际行为；若更改破坏功能，请撤销。
见[直连还是走隧道](split-tunneling.md)。
