# 能做到与做不到什么

## 能做到

把 VPN 在*设备上的迹象*对你选定的应用隐藏起来——应用通过 Java API、内核和 libc 读到
的网络信号；已安装的 VPN 客户端的存在；以及本地回环上的 VPN/代理端口。不同应用探测
不同的东西，VPN Hide 对每种都有一个角色：**Java**、**Native**、**Apps**、**Ports**。

## 做不到

- **改变你的外部 IP。** 流量经过隧道时，服务器看到的是 VPN 的出口 IP。在服务器端运行、或按 IP 判断的
  反欺诈与地理检测在手机之外——设备无法隐藏它。
- **绕过服务器端或账号级检测。** 如果某服务在它自己的后端判定你在用 VPN，设备上的
  隐藏改变不了这个结论。
- **隐藏你已 root 或在用自定义 ROM，或让应用通过 Play Integrity。** VPN Hide 只隐藏
  VPN，别无其他。若某应用因检测到 root 或通不过完整性认证而拒绝，那是另一码事，不是
  本工具要做的。
- **无 root 运行。** VPN Hide Core 模块必须有 root。Java/Apps 需要 LSPosed，Native 需要原生后端，
  Ports 随核心模块提供。可以少用一些层，但覆盖会减少。
- **对无限多的应用启用 Native。** Core 提供适用上限与 UID 清单，选择器立即阻止超量选择。
  仍需点击保存，Core 会再次验证。共享 UID 只计一次，而资料/分身副本可能增加 UID。
  清单不完整或超过上限时，不能悄悄截断保护范围。见[工作资料](work-profiles.md)。
- **击败游戏自身的反作弊。** 把 VPN 对你正在玩的那款游戏隐藏、以绕过它的检查，是另一
  回事，VPN Hide 并不保证——见[游戏加速器](game-accelerators.md)。

## 路由是独立选择

目标可在隧道内或外。VPN Hide 不配置 VPN 客户端的路由策略，但 Java 钩子可能改变
返回给应用的网络。在 Android 和 VPN 策略允许绕过时，绑定该网络可能直连。
隐藏检查不能证明流量留在隧道内。见[直连还是走隧道](split-tunneling.md)和
[安全与隐私](security-and-privacy.md)。
