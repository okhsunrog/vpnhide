# 关闭、重置与卸载

## 暂停隐藏而不移除任何东西

要对某个应用停止隐藏，在选择器里移除它的角色并保存。要临时停掉全部，在 root
管理器里停用模块（以及 LSPosed 模块）——之后可以再启用。

## 彻底移除 VPN Hide

顺序很重要，因为应用需要先确认没有任何东西仍在生效，才能进行清理：

1. 在 root 管理器里**移除所有 VPN Hide 模块**——Native 后端（内核模块 / KPM /
   Zygisk）和 Ports。
2. **在 LSPosed 里停用 VPN Hide 模块。**
3. **重启。**

## 移除残留文件

VPN Hide 及其模块还会在各自模块目录**之外**写入配置、状态、统计和目标文件。要
删除它们，使用 **Settings → Remove leftover files**。这会永久删除它们，且**无法
撤销**。

在完成上述步骤前该界面不会执行：如果仍有模块已安装或仍有挂钩已加载，它会列出到底
是什么在阻拦（内核模块、KPM、Zygisk、Ports、等待重启的内核挂钩，或 LSPosed
挂钩），以便你先清除并重启。完成后，它会提供 **Uninstall VPN Hide**（应用本身）。

如果你只是刷机或更换设备，多半应当保留配置——[请先导出](config-backup.md)。
