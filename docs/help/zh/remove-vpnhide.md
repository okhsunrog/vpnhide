# 暂停、重置与卸载

## 对单个应用暂停隐藏

在「**隐藏**」清除其角色并保存成功，然后强制停止并重新打开。新进程也不会保留原来的
Zygisk 钩子。仅在 root 管理器中停用模块不会移除已加载钩子；更改安装/启用状态后请重启。
若之后想恢复选择，请先[备份配置](config-backup.md)。

## 移除安装与残留文件

1. 如果以后可能需要，先导出配置。
2. Core 仍可用时清除角色并保存，然后在 LSPosed 中停用 VPN Hide。
3. 移除 Core 之前，打开 **Settings → Remove leftover files** 查看阻碍。
   已加载的内核或进程钩子可能需要由你决定重启，或启动不含 VPN Hide 的内核；删除文件不会卸载钩子。
4. 仅在 Core 确认安全时执行清理。如果本测试版无法达到该状态，请保留配置与 Core 并收集报告，
   不要删除日志或绕过未知效果的保持状态。
5. 清理完成后，通过 root 管理器移除 **VPN Hide Core**，再卸载 APK，按管理器说明重启。

统一安装无需单独卸载后端 ZIP。旧版本遗留模块需要明确的迁移/恢复流程。
清理会永久删除配置；只卸载 APK 不会执行清理。

## 自行编译的 Built-in 内核

这是高级集成方式，并非普通的预编译内核下载选项，也没有可卸载的模块：代码已编译进
运行中的内核。完整清理需要**启动不含 VPN Hide 的内核**，同时移除其他模块并停用 LSPosed。再次启动同一个 Built-in 内核不会解除清理阻碍。
拆除自行集成方案之前，请先规划如何恢复内核。
