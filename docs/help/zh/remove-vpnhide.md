# 暂停、重置与卸载

## 对单个应用暂停隐藏

在「**隐藏**」清除其角色并保存成功，然后强制停止并重新打开。新进程也不会保留原来的
Zygisk 钩子。仅在 root 管理器中停用模块不会移除已加载钩子；更改安装/启用状态后请重启。
若之后想恢复选择，请先[备份配置](config-backup.md)。

## 移除安装与残留文件

1. 如果以后可能需要，先导出配置。
2. 在 root 管理器中移除 VPN Hide 原生模块和 Ports。
3. 在 LSPosed 中停用 VPN Hide，然后**重启**。
4. 打开 **Settings → Remove leftover files**，先解决列出的阻碍。
5. 执行清理，再使用提供的卸载操作移除 APK。

清理会永久删除模块目录之外的配置和其他持久文件，无法撤销。只卸载 APK 不会完成此清理。

## 自行编译的 Built-in 内核

这是高级集成方式，并非普通的预编译内核下载选项。删除配套组件不会删除运行内核中的
已编译代码。完整清理需要移除配套组件并**启动不含 VPN Hide 的内核**，同时移除其他
模块并停用 LSPosed。再次启动同一个 Built-in 内核不会解除清理阻碍。
拆除自行集成方案之前，请先规划如何恢复内核。
