# 暂停、重置与卸载

## 对单个应用暂停隐藏

在「**隐藏**」清除其角色并保存成功，然后强制停止并重新打开。新进程也不会保留原来的
Zygisk 钩子。仅在 root 管理器中停用模块不会移除已加载钩子；更改安装/启用状态后请重启。
若之后想恢复选择，请先[备份配置](config-backup.md)。

## 移除安装与残留文件

1. 如果以后可能需要，先导出配置。
2. 在 root 管理器中移除 VPN Hide 的原生后端模块（内核模块、KPM 或 Zygisk）。
   **暂时保留 VPN Hide Core 模块**：清理由它执行。
3. 在 LSPosed 中停用 VPN Hide，然后**重启**。
4. 打开 **Settings → Remove leftover files**，先解决列出的阻碍。
5. 执行清理，然后在 root 管理器中卸载 **VPN Hide Core** 模块，使用提供的操作移除 APK，并重启。

清理会永久删除模块目录之外的配置和其他持久文件，无法撤销。只卸载 APK 不会完成此清理。

## 自行编译的 Built-in 内核

这是高级集成方式，并非普通的预编译内核下载选项，也没有可卸载的模块：代码已编译进
运行中的内核。完整清理需要**启动不含 VPN Hide 的内核**，同时移除其他模块并停用 LSPosed。再次启动同一个 Built-in 内核不会解除清理阻碍。
拆除自行集成方案之前，请先规划如何恢复内核。
