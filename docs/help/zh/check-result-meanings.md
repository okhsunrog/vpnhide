# 每个结果是什么意思

每项检查针对一种检测向量报告一个结果。

- **已隐藏**——应用一侧已看不到 VPN，而 root 仍能看到。这一层对该向量起作用。
- **被检测到**——应用仍能通过该向量看到 VPN。隐藏没有覆盖它。开启覆盖它的角色或后端
  （通常是 **Native**，仅 **Java** 不够时），保存，然后重启应用。
- **由 SELinux 覆盖**——该向量被系统的 SELinux 策略挡下，而不是被 VPN Hide 的钩子。
  在这台设备上它实际上被隐藏了，但这不是 VPN Hide 做的——因此因 ROM 而异。
- **未测量**——检查无法运行。通常是一个门槛：VPN 关着、VPN Hide 没走这条 VPN，或应用
  刚为自己开启隐藏、需要重启。修正门槛后重新运行。

## 你可能看到的门槛（而不是结果）

- **VPN 已关闭**——开启 VPN 后重新检查。
- **没有走这条 VPN**——见[自检检查什么](what-the-check-proves.md)。
- **重启 VPN Hide**——你刚把 VPN Hide 加为目标；强制停止并重新打开它，让它自己的钩子
  生效，然后重新检查。无需重启设备。
