# 诊断结果的含义

- **已证明**：在记录的上下文中，必需 RAW 信号、受保护结果和普通对象保留控制均已验证。
- **泄漏**：受保护 worker 仍能看到测试信号。其他检查不完整不会消除这个证据。
- **未验证**：测试信号、观察、控制或归因不完整。空列表或干净的 Java 响应本身不能证明隐藏。
- **基础设施错误**：Core 无法准备、启动或完成 worker/fixture。阅读详细原因，解决后点击**重试**。
- **清理未完成**：无法确认测试资源已删除。Core 保留该状态并阻止不安全的重用。

## 保存的证据

断线、配置改变或一次运行中断后，旧证据仍可显示。请结合其时效和来源上下文解读。
先恢复 Core 连接或解决结果未知的操作，再把结果视为当前状态。

无需打开 VPN，也无需将 VPN Hide 加入分流名单。Dashboard 可用性与这些设置无关。
新 worker 的结果也不能证明旧游戏进程已更新；保存后请重启目标应用。

参见[诊断检查什么](what-the-check-proves.md)和[保存与应用](saving-applying.md)。
