# 备份、恢复与迁移配置

你的整套设置——哪些应用是什么角色、端口规则、各项选项——都保存在单一的规范
JSON 配置里。你可以在 **Settings → Configuration → Config backup** 保存、恢复它，
或迁移到另一台设备。

## 导出与导入

- **Export JSON**——把当前配置保存到你选择的文件。
- **Import JSON**——从文件加载配置。**导入会替换**当前配置（不是合并），并立即
  重新应用已安装的模块。

在大改动或全新刷机前留一份导出副本，这样一次导入就能找回你的设置。

## 迁移到另一台设备

1. 在旧设备上 **Export JSON**。
2. 在新设备上安装 VPN Hide 以及你使用的相同模块。
3. 对导出的文件执行 **Import JSON**。

角色按包名绑定到应用，所以任何在新设备上尚未安装的目标应用，会一直保留在配置里，
直到你安装它。

## 导入旧的（1.0 之前）配置

如果 VPN Hide 发现一份由 **1.0 之前**版本写入的配置，而你已经设置了一些应用，它
不会悄悄导入——而是显示一个横幅，并在 **Settings → Pre-1.0 configuration** 提供
三个选项：

- **Merge**——保留当前配置的一切，并在其上叠加旧的角色。
- **Replace**——丢弃当前应用列表，改用旧的（无论哪种方式，你的自动隐藏设置和
  VPN Hide 自身的条目都会保留）。
- **Delete**——不读取即删除旧文件；如果你已经重新设置好，只想把它们从设备上清掉，
  就选这个。

这三个选项都会**删除旧文件**，且无法撤销。
