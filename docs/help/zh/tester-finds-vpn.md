# 第三方检测器仍发现 VPN

VPN Hide 的检查都通过了，但某个检测应用（或网站测试）仍报告有 VPN。这不一定矛盾——
两者测量的东西不同。

## 拿同类去比

- VPN Hide 的检查验证的是**设备上**的隐藏：应用在本地能读到的网络信息。通过就说明
  这些向量被隐藏了。
- 第三方检测器可能还依据设备无法隐藏的东西：
  - **你的出口 IP。** 数据库会标记已知的 VPN/机房 IP 段。这在服务器端、在手机之外——
    设备上的隐藏改变不了它。
  - **你没开启的向量。** 如果检测器读取已安装的软件包或本地回环端口，而你只开了
    **Java + Native**，请加上 **Apps** 或 **Ports**。
  - **缓存的结果。** 强制停止并重新打开检测器，让它重新探测。

## 如果 VPN Hide 自己报告「被检测到」

那就是确实有某个向量在泄露。开启覆盖它的角色或后端（见[每个结果是什么
意思](check-result-meanings.md)），然后重新检查。若保存并重启后仍泄露，请收集一份
[调试报告](collect-report.md)。
