# 安装 Zygisk 模块

Zygisk 通过目标进程内的 libc 钩子提供原生隐藏。完整 Core ZIP 中只包含一对 ABI
payload。按[Core 安装步骤](first-install.md)操作，无需单独的 VPN Hide Zygisk ZIP。

## 需要知道的

直接系统调用可以绕过这些钩子，应用也可能检测自身进程内的修改。配置角色时请参考
Core 报告的覆盖范围。Java/LSPosed 提供独立的一层。

## 要求

需要兼容的 Zygisk 提供程序。提供程序发现 payload、Core 授权及应用实际安装钩子是不同
事实。仅有 LSPosed 并不能证明 VPN Hide payload 已就绪。

## 步骤

1. 安装配套的 APK 和通用 Core ZIP。
2. 配置所需提供程序和 Java 层作用域。
3. 安装或 Core 的切换状态要求重启时，重启并解锁设备。
4. 选择目标角色并点击**保存**。

等待重启或尚未验证的后端不代表保护已启用。按仪表盘提示操作，求助时保留诊断错误。

## 更改如何生效

已经运行的应用可能仍使用旧的钩子策略。修改配置后，强行停止并重新打开目标应用。
提供程序发现目录的变更可能需要设备重启；仅重启应用不能保证重新发现。Core 负责投递
和当前启动的授权，无需手动编辑目标文件。新诊断进程的结果不能证明所有旧游戏进程
都已更新。
