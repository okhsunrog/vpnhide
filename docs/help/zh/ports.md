# 隐藏 localhost 端口（Ports）

有些 VPN 和代理客户端会运行一个本地守护进程——Clash、Sing-box、V2Ray、Amnezia
之类——监听某个 `localhost` 端口，如 `127.0.0.1:7890`。应用可以用
`connect(127.0.0.1, PORT)` 探测这些端口，从而猜到有 VPN 或代理在运行，即使接口
本身已被隐藏。**Ports** 角色为你选中的应用堵住这个缺口。

## 它做什么

对于标记为 Ports 目标的应用，VPN Hide 会阻断它对 loopback 地址的访问。探测会
返回 *connection refused*——与真正关闭的端口无法区分。阻断是**按应用**的：你的
VPN 客户端和系统其余部分照常使用 localhost。

默认会为该应用阻断整个 loopback 范围，这对典型观察方（银行、政务、电商等应用）
是安全的：它们并不会合法使用 localhost。**浏览器是例外**（开发者工具、PWA 和
已安装的 Web 应用确实会用到 localhost），所以别把浏览器加为 Ports 目标即可。

## 如何开启

1. 通过 root 管理器的 **Modules** 界面安装 **Ports** 模块（`vpnhide-ports.zip`）。
   不一定需要重启——应用在保存时会重新应用规则。
2. 在应用的 **Hiding** 标签中，给应用赋予 **Ports** / **P** 角色（角色标签旁的
   设置图标）。
3. 保存。规则立即生效。

## 收窄到特定端口

如果对某个应用阻断整个 loopback 范围过宽，Ports 角色旁的同一个设置图标还可以让
你改为设置要阻断的**特定端口范围**。它们以精确规则保存，因此导出或导入的配置会
保持相同行为。

## 如何移除

从 root 管理器的 Modules 界面卸载 Ports 模块。注意：防火墙规则在每次开机和每次
保存时都会重新应用；移除角色（或模块）并保存即可清除它们。
