# 工作资料、克隆与第二空间

**只在主资料（main profile）中安装 VPN Hide。**从那里它就已经覆盖了一切——你
不需要在工作资料、第二空间或克隆空间里再装一份。

## 为什么一份就够

Java 层挂钩 `system_server`，而它**只在主资料中**运行。主资料里的选择器已经列出
设备上所有资料的应用，并对它们全部应用隐藏。工作资料或第二空间里的第二份无法额外
挂钩任何东西——更糟的是，多余的副本会互相抢着把 **Save** 写入共享配置，从而彼此
覆盖。

如果应用发现自己被安装在多个资料中，仪表盘会提醒你并指出多余的副本。请从工作
资料 / 第二空间 / 其他次级资料中卸载 VPN Hide，只保留主资料里的那一份。

## 对工作资料或克隆内的应用隐藏 VPN

这仍然从主资料的选择器里控制——克隆和工作资料的应用会显示在那里（标为 **Work
profile** 或 **Cloned app**），可以像其他应用一样赋予角色。次级一侧无需安装任何
东西。

有一点要注意：你在多个资料里都给某应用开启了 **Native** 时，它在每个资料各算一个
UID，计入 Native 上限，因此克隆会让这个额度消耗得快一倍——见
[能做到与做不到什么](capabilities-limits.md)。
