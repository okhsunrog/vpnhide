# 工作资料、克隆与第二空间

**仅在主资料中安装和配置 VPN Hide。** Java 钩子运行在系统共用的 `system_server` 中，
不需要在每个资料中安装一份。应用会阻止在次要资料中使用其界面；若提示有多余副本，请移除。

## 一个包，一套选择

主资料中的列表汇集各资料中的软件包及 UID。同一包安装在多个资料中时，在列表中共用
一套选择，并显示资料信息。角色和钩子设置应用于所有已发现的副本。
**不能给同一包的个人版和工作版配置不同角色。** 包名不同的克隆则可以单独配置。

Native 上限按不同 UID 计算，而不是按列表行数；一个包在两个资料中通常占两个名额。
VPN Hide 自身只预留主资料 UID 的名额。见[限制](capabilities-limits.md)。

若看不到某资料的应用或扫描不完整，请检查该资料是否可用，然后重试加载列表。
缺少列表项不代表已保存的配置被删除。资料与 VPN 路由是两件事；排查时请确认目标应用
所在资料以及实际使用的 VPN 路由。
