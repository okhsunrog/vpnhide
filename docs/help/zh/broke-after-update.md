# 更新后不工作了

Android 更新、root 管理器更新，或 VPN Hide 更新，都可能让各部分错位一次重启。

## 检查这些

- **版本不一致。** 仪表盘会显示应用版本和*正在运行的模块版本*。如果不同，说明新模块
  可能还没加载。安装匹配组件后**重启**；若警告仍在，检查哪个组件尚需更新，
  并非每次版本不匹配都只缺一次重启。
- **内核变了。** 系统更新可能更换内核。为旧内核编译的内核模块可能加载失败（「Unknown
  symbol」「未生效」）。重新安装与新内核匹配的原生后端，或改用仪表盘现在推荐的那个。
- **LSPosed 作用域丢失。** 有些更新会重置模块作用域。确认**系统框架**仍在 VPN Hide 的
  作用域里。
- **目标应用更新了。** 它可能新增了检测手段。打开它，如果又报错，重新检查它的角色：也许
  原来只用 **Java** 就够，现在需要 **Native** 或 **Apps**。

重启后，仪表盘应再次显示所有模块 **Active**。如果某后端在新内核上无法加载，见[模块已安装
但未生效](module-not-active.md)。
