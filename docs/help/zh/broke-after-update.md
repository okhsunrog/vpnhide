# 更新后不工作了

Android、root 管理器或 VPN Hide 更新可能改变兼容性与加载版本。
更改安装之前，请先检查实际报告的状态。

## 检查这些

- **版本不一致：**检查兼容的 APK/Core 文件与实际运行代次。暂存的 Core 替换需要相应的生命周期
  边界；仅更新兼容的客户端界面 APK 不意味着重新安装 Core。
- **内核变化：**Core 根据包内已验证目录确定候选项。保留兼容性/加载错误，不要手动选择 GKI ZIP
  或安装独立后端归档。
- **LSPosed 作用域变化：**确认 VPN Hide 的作用域仍含**系统框架**。已安装 APK 可能与其中已加载
  的代码不同。
- **目标应用更新：**检查角色，保存后重启目标应用；它可能新增了检测方式。

重启不保证所有后端都会启用。请查看具体的准备、配置交付与测量覆盖状态。
见[模块已安装但未生效](module-not-active.md)。
