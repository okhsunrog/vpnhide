# 你的第一个应用，分步操作

以银行应用为例，隐藏受支持的 VPN 信号。完整参考见[设置隐藏](configure-hiding.md)。

1. 如果银行会扫描已安装的 VPN 应用，先打开[隐藏 VPN 应用](vpnhide://hidden-apps)，
   将 VPN 客户端加入隐藏名单并保存。请在编辑银行的角色之前完成这一步。
2. 打开「**隐藏**」标签页，通过搜索找到银行。
3. 开启 **Java** 和 **Native**；如果已设置隐藏名单，再开启 **Apps**。
4. 离开此页面前点击**保存**。有未保存更改时进入另一个编辑器，可能需要放弃角色更改。
5. 强制停止并重新打开银行，让它重新检查。

角色配置在**银行**上，而不是 VPN 客户端上。如果仍被拒绝，见
[应用仍要求关闭 VPN](app-still-requires-vpn-off.md)。服务器可能拒绝 VPN 出口 IP，
但仅凭拒绝不能确定原因。更改路由前，先决定直连是否符合你的需求：
[直连还是走隧道](split-tunneling.md)。
