# 你的第一个应用，分步操作

一个快速示例：把 VPN 对某个银行应用隐藏。完整参考见[设置隐藏](configure-hiding.md)。

1. 打开「**隐藏**」标签页。
2. 找到你要对其隐藏 VPN 的应用——你的银行。列表很长时用搜索。
3. 为它开启 **Java** 和 **Native**。两者合起来覆盖应用通过 Android Java API 以及
   通过内核或 libc 读取到的 VPN 信号。
4. 如果银行还会扫描已安装的 VPN 应用，就为它开启 **Apps**，并确认你的 VPN 客户端
   （WireGuard 等）在隐藏名单里——[隐藏 VPN 应用](vpnhide://hidden-apps)。
5. 点击**保存**。
6. 强制停止并重新打开银行应用，让它重新检查。

记住：角色配置在**银行**上，而不是 VPN 客户端上。VPN 客户端才是被隐藏的一方。如果
银行仍然拒绝，请按[设置隐藏](configure-hiding.md)排查。
