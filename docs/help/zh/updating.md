# 更新应用与模块

VPN Hide 使用 APK 和一个完整的 **VPN Hide Core** ZIP。Core 内含原生组件并选择适用的后端。
请使用[同一官方发布版本](https://github.com/okhsunrog/vpnhide/releases)中的兼容文件。
本测试版的 Zygisk 发布生命周期仍在重新评审；仅有归档布局并不能证明后端已经可用。

## 如何更新

- 用新 APK 覆盖安装旧版。
- 更新 Core 时，通过 root 管理器的 Modules 页面安装**完整 Core ZIP**，然后重启以启用已暂存的替换版本。
- 查看仪表盘中的兼容性与实际运行版本信息。

仅更新兼容的客户端界面 APK，本身不要求重新安装 Core。
无需单独下载 kmod、KPM 或 Zygisk ZIP，也无需手动选择 GKI 文件。

## 从 1.x 升级

先准备并验证替换版本，保留配置，再按完整 Core 包的迁移说明处理旧模块。
Ports/Built-in 模块与独立后端的启动脚本属于旧布局；移除它们之前，替换版本必须已经就绪。
本测试版的统一自动维护流程仍在实现中。

## 版本不一致的警告

按具体运行组件的警告操作。检查 APK/Core 协议兼容性与实际加载的代次，不能仅凭版本号接近
就认定兼容。Core RPC 或日志版本变化本身不要求重新编译自行集成的 Built-in 内核。

## 系统更新后立刻不工作了

内核更新可能改变模块兼容性或 LSPosed 作用域。Core 根据已验证的目录确定候选项。
保留错误信息并查看[更新后不工作了](broke-after-update.md)，不要轮流尝试任意后端归档。

## 只更新 APK 也要重启

当更改后的 LSPosed 代码需要替换已经加载到 `system_server` 的代码时，需要重启。
仅更新兼容的客户端界面 APK 有不同的生命周期。请查看实际运行版本与所需操作。
重启无法替换尚未更新的旧 Core 包。

自行集成的 Built-in 属于内核代码，替换 APK 或 Core ZIP 不会替换该集成。
