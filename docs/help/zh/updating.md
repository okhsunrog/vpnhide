# 更新应用与模块

VPN Hide 由应用加上 **VPN Hide Core** 模块和一个原生后端模块组成。让它们的版本**保持同步**
——更新应用时也更新核心和后端模块，之后重启。应用和核心必须来自同一版本：版本不一致时，
应用会显示 **“VPN Hide Core 版本不匹配”**，直到二者一致。

## 如何更新

- **应用**——用发布页的较新 APK 覆盖安装旧版。
- **模块**（核心、内核模块、KPM、Zygisk）——通过 root 管理器（KernelSU /
  Magisk / APatch）的 **Modules** 界面安装较新的 ZIP，然后**重启**。

## 从 1.x 升级

2.0 用核心模块取代了各模块的激活器。安装 `vpnhide-core.zip`，更新原生后端 ZIP，然后**卸载**
旧的 **VPN Hide (Ports)** 和 **VPN Hide (Built-in kernel)** 模块（如有）——2.0 没有这些模块，
它们旧的开机脚本会干扰核心（只要仍安装着，仪表盘就会显示错误）。重启。已保存的应用角色会保留。

## 版本不一致的警告

当版本彼此偏离时，仪表盘会提示：

- *“模块版本 X 早于应用版本 Y”*——更新该模块（打开 root 管理器 → Modules）。
- *“模块版本 X 新于应用版本 Y”*——更新 VPN Hide 应用。

请按具体组件的警告操作，不要以版本号差距小来判断不匹配无害。

## 系统更新后立刻不工作了

系统或内核更新可能改变内核，使 `.ko` 不再加载（它的 GKI 接口变了），或者重置你
的 LSPosed 作用域。这是另一种情况，有各自的解决办法——见
[更新后不工作了](broke-after-update.md)。

## 只更新 APK 也要重启

替换 APK 后，应用进程可能已更新，但 `system_server` 中加载的 LSPosed 代码仍是旧版。
即使只更新 APK 也请重启。然后检查仪表盘中的运行版本与应用错误；重启不能更新尚未替换的旧 ZIP。

尽可能使用[同一官方发布版本](https://github.com/okhsunrog/vpnhide/releases)的组件。
自行集成 Built-in 时，替换 APK 或核心模块不会替换内核代码，需要单独更新自己的内核集成。
