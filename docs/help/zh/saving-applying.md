# 更改何时生效

在选择器里保存会写入你的配置并立即重跑当前的 Native 后端。但已经在运行的目标
应用可能**缓存**了旧视图——它的网络状态，以及启动时做过的任何 VPN 检查。所以
可靠的应用方式是：

1. 在应用里**保存**。
2. **强制停止目标应用**（Android 设置 → 应用 → 该应用 → 强制停止）再重新打开，
   让它重新读取全新的、已隐藏的视图。

## 按后端

- **Java（LSPosed）和 Native（kmod / KPM）**——保存后新配置立即生效；重启目标
  应用以清除它的缓存状态。
- **Zygisk**——挂钩在应用进程启动时安装，因此配置更改**只**在全新启动时生效。
  强制停止并重新打开该应用。

## 需要重启的情形

- **安装、更新、启用或停用某个模块**（任何 Native 后端或 Ports）——重启以加载。
- **实验性保护**（隐藏文件系统路径）在 kmod / KPM 上——需要重启；在 Zygisk 上则
  在重启选定应用后生效。

## 仪表盘上的检查结果同样是缓存的

仪表盘上的自检结果反映的是上一次运行。更改配置后，重启目标应用（必要时还有你的
VPN）并重新检查——见[第三方检测器仍发现 VPN](tester-finds-vpn.md)。
