# 自检检查什么

**诊断**页面运行 VPN Hide 自己的检查：对每一种检测向量，它把目标应用会看到的内容和
以 root 观察到的真实状态作对比。如果从应用一侧已看不到 VPN，而 root 仍能看到，这个
向量就是**已隐藏**。

## 「通过」意味着什么

一次通过意味着隐藏层在你的设备上确实起作用，针对被测的这些向量。这些检查测量的正是
那些把 VPN 对你的目标应用隐藏起来的钩子——同一条 code path，而不是打了折扣的替身——
所以「通过」是隐藏起作用的真实信号。这也正是仪表盘能显示「VPN 已隐藏」的原因。

## 运行需要什么

- **必须开着 VPN**——否则没有可隐藏的东西，检查也无从测量。
- **VPN Hide 必须走这条 VPN。** 如果没有（有些分应用 VPN 和游戏加速器只代理选定的
  应用），应用一侧的探测即使不隐藏也看不到 VPN，所以检查无法运行。页面会提示；这是
  一个要去修正的状态，不是失败。

## 它证明不了什么

「通过」并不保证*某个具体的*第三方应用会放你进去。应用仍可能因设备之外的原因拒绝——
对出口 IP 的服务器端检测、你尚未覆盖的已安装应用扫描，或它在你保存之前缓存的结果。见
[第三方检测器仍发现 VPN](tester-finds-vpn.md)。
