# 诊断检查什么

Core 在后台执行诊断并保存证据。打开应用、Dashboard、诊断或导出只读取这些证据，
不会启动检查套件。点击**重试**才会明确请求新的一次检查。

诊断使用自身有时限的测试对象和独立的 Android worker 进程。你的 VPN 可以关闭，
VPN Hide 也可以被排除在 VPN 客户端的隧道之外。这些设置不会阻止 Dashboard 或诊断。

## 证据能证明什么

只有 RAW 阶段出现明确的测试信号、受保护阶段取得正确观察结果，且普通网络对象的
保留控制通过，才能证明一个检测向量。空响应本身不能证明隐藏。另一项检查未完成，
不会消除已经确认的泄漏。必需向量来自支持契约和已启用功能，而非仅来自安装成功的 hooks。

## 范围与限制

证据属于记录中的 worker、策略和已加载代次。新的 worker 通过检查，不代表已经运行
的游戏已获得新 hooks 或配置。保存后应重启目标应用并检查其实际行为。
网络切换和不同 callback 注册方式需要各自的控制。

此 beta 仍有未验证向量和设备验收项目。缺失证据会明确显示；backend 安装成功或
配置已送达不等于保护检查通过。参见[结果含义](check-result-meanings.md)。

第三方应用也可能因服务器 IP 检查、缓存或其他检测方式拒绝运行。请在
[调试报告](collect-report.md)中提供复现步骤和应用版本。
