## English

VPN Hide Core now notes leftover 1.x modules (`vpnhide_ports`, `vpnhide_builtin`) in its own log and boot status at every boot, so a debug report shows them even if the app was never opened. The Dashboard keeps warning about them as before.

## Русский

VPN Hide Core теперь при каждой загрузке записывает оставшиеся модули 1.x (`vpnhide_ports`, `vpnhide_builtin`) в свой журнал и в статус загрузки, поэтому они видны в отладочном отчёте, даже если приложение ни разу не открывали. Главный экран по-прежнему предупреждает о них.
