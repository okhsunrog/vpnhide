## English

When VPN Hide Core is missing or not running, the startup screen now says so and tells you to install vpnhide-core.zip, instead of asking for a root grant the app no longer needs. A core module from a different release gets its own "version mismatch" screen. Full reset now tells you to keep the core module installed until the reset is done.

## Русский

Если VPN Hide Core не установлен или не запущен, стартовый экран теперь так и говорит и предлагает установить vpnhide-core.zip, а не просит root-доступ, который приложению больше не нужен. Для модуля core из другого релиза есть отдельный экран «версия не совпадает». Полный сброс теперь предупреждает, что модуль core нужно оставить установленным до конца сброса.
