## English

Experimental local HTTP bridge with a host MCP server for adb-driven app-state and hiding management. Off by default; enable it under Settings → Developer → Agent control.

## Русский

Экспериментальный локальный HTTP-мост и MCP-сервер на хосте для управления состоянием приложения и скрытием через adb. Выключен по умолчанию; включается в Настройки → Для разработчиков → Agent control.
