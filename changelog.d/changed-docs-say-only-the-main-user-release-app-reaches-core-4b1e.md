## English

The README, the in-app guide and the startup screen now say that only the release app installed in the main Android user can connect to VPN Hide Core. A `.dev` test build, or a copy in a secondary user, work profile or clone space, always stays on the startup screen.

## Русский

В README, встроенной справке и на стартовом экране теперь сказано, что к VPN Hide Core подключается только релизное приложение в основном пользователе Android. Тестовая сборка `.dev`, а также копия во вторичном пользователе, рабочем профиле или пространстве клонов всегда остаются на стартовом экране.
