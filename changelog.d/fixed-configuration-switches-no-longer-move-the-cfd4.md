## English

Configuration switches no longer move the screen while saving. Progress stays inside the switch; errors appear as overlays with recovery actions.

## Русский

Переключатели конфигурации больше не сдвигают экран при сохранении. Прогресс отображается внутри переключателя, ошибки — поверх экрана с доступными действиями восстановления.
