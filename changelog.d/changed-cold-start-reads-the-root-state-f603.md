## English

Cold start reads the root state once: the startup self-target check now feeds the dashboard directly instead of the app running the same root read twice.

## Русский

Холодный запуск читает root-состояние один раз: стартовая проверка своих целей теперь напрямую питает панель, а не заставляет приложение выполнять одно и то же root-чтение дважды.
