## English

Per-app hook selection: choose which Java and native hooks apply to each protected app, grouped by detection method with an explanation of what each method is and how an app uses it to detect a VPN. Full role labels (Java / Native / Apps / Ports) are shown by default.

## Русский

Выбор Java- и нативных хуков отдельно для каждого защищаемого приложения: хуки сгруппированы по способам детекта, с пояснением, что это за способ и как приложение через него определяет VPN. Полные названия ролей (Java / Native / Apps / Ports) показываются по умолчанию.
