## English

The agent bridge no longer crashes the app when its client disconnects mid-request, for example when a configuration change makes VPN Hide itself a ports target and the ports module resets the app's own localhost connections.

## Русский

Агентский мост больше не роняет приложение, если клиент отключается посреди запроса, например когда после изменения настроек VPN Hide сам становится целью модуля портов и тот сбрасывает его localhost-соединения.
