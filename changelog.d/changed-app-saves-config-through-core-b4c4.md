## English

The app now saves settings only through the core module: it talks to vpnhide-core directly over a private socket in its own data directory, with no root shell. Native and port hiding are applied by core in the same operation. Requires the vpnhide-core module.

## Русский

Приложение теперь сохраняет настройки только через модуль core: оно обращается к vpnhide-core напрямую через приватный сокет в собственном каталоге данных, без root-оболочки. Нативное скрытие и скрытие портов применяет core в той же операции. Требуется модуль vpnhide-core.
