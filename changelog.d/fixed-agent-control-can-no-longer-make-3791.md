## English

Agent control can no longer make VPN Hide itself a target of the ports module. That setting rejected the app's own localhost connections, which cut the agent bridge off until the change was reverted by hand; VPN Hide's own roles are now fixed on every write path.

## Русский

Agent control больше не может сделать сам VPN Hide целью модуля портов. Такая настройка блокировала localhost-соединения самого приложения и отрезала агентский мост, пока изменение не откатывали вручную; теперь роли самого VPN Hide фиксированы на всех путях записи.
