## English

V2 development core can select and directly load the kmod backend, adopt built-in without a bridge, and refuse loading when KPM state is active or unknown.

## Русский

В разрабатываемой V2 core выбирает и напрямую загружает kmod, использует built-in без bridge-модуля и запрещает загрузку при активном или неизвестном состоянии KPM.
