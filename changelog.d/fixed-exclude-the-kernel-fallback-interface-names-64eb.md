## English

Exclude the kernel fallback interface names tunl0, gre0 and gretap0 from VPN matching while preserving detection of other tunl-prefixed tunnels.

## Русский

Имена резервных интерфейсов ядра tunl0, gre0 и gretap0 исключены из распознавания VPN; остальные туннели с префиксом tunl по-прежнему распознаются.
