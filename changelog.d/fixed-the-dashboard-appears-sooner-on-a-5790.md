## English

The dashboard appears sooner on a cold start: the startup runtime re-activation now runs after the first screen is shown instead of forcing a second root read while the screen is still loading.

## Русский

Панель появляется быстрее при холодном запуске: повторная активация при старте теперь выполняется после показа первого экрана, а не заставляет перечитывать root-состояние, пока экран ещё грузится.
