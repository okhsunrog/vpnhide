## English

Choose an explicit kernel backend for the next device boot in advanced settings. Core validates compatibility and all configured targets; the current backend stays running. Picker capacity checks cover both current and staged backends, with Save/Cancel unchanged.

## Русский

В расширенных настройках можно выбрать kernel-бэкенд для следующей загрузки устройства. Core проверяет совместимость и все настроенные приложения; текущий бэкенд продолжает работать. Проверка вместимости учитывает текущий и выбранный бэкенды, кнопки «Сохранить» и «Отмена» сохранены.
