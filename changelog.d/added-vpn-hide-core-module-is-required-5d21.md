## English

New required VPN Hide Core module (vpnhide-core.zip). It is the only component that loads the native backend (kmod, KPM, Zygisk, or adopts a built-in kernel backend), writes the config and applies Ports rules. Every save is a journalled operation: an interrupted save is finished or rolled back safely after a restart, and retries never apply twice. Install the app and vpnhide-core.zip from the same release.

## Русский

Новый обязательный модуль VPN Hide Core (vpnhide-core.zip). Только он загружает нативный бэкенд (kmod, KPM, Zygisk или подхватывает встроенный в ядро бэкенд), пишет конфиг и применяет правила Ports. Каждое сохранение — операция с журналом: прерванное сохранение после перезапуска безопасно доводится до конца или откатывается, а повтор никогда не применяется дважды. Устанавливайте приложение и vpnhide-core.zip из одного релиза.
