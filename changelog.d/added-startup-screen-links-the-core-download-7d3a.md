## English

When VPN Hide Core is missing, not running or from a different release, the startup screen now has a button that downloads `vpnhide-core.zip`, the same kind of download button the Dashboard shows for other modules.

## Русский

Если VPN Hide Core не установлен, не запущен или относится к другому релизу, на стартовом экране теперь есть кнопка загрузки `vpnhide-core.zip` — такая же, какую главный экран показывает для других модулей.
